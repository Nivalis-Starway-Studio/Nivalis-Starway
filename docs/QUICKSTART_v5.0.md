## 新功能3：总小码币修改

### 改进内容
- ✏️ 现在可以双击直接修改学生的总小码币数量
- 🔧 系统自动计算并同步累计币数
- 💾 修改后立即保存，数据安全可靠

### 操作步骤

#### 1. 进入班级详情
- 在主界面点击任意班级卡片

#### 2. 修改总小码币
- 在学生列表中找到要修改的学生
- **双击**"总小码币/累计"列（最后一列）
- 输入新的总小码币数量（0-10000）
- 点击"确定"

#### 3. 查看结果
- 表格自动刷新，显示新的总币数量
- 班级统计信息同步更新
- 数据已自动保存

### 使用示例

**场景**：张三同前总币50（本周5，累计45），需要调整为80

**操作**：
```
1. 双击张三的"总小码币/累计"列
2. 在对话框中输入：80
3. 点击确定
```

**结果**：
```
总小码币：50 → 80
本周币：5（保持不变）
累计币：45 → 75（自动计算）
```

### 原理说明
```
总小码币 = 累计币 + 本周币

修改总币时：
- 输入新的总小码币
- 保持本周币不变
- 自动计算：累计币 = 新总币 - 本周币
```

### 注意事项
- ⚠️ 本周币会保持不变，只调整累计币
- ⚠️ 如果新总币小于本周币，累计币会被设为0
- ⚠️ 修改后立即生效，无法撤销（数据已保存）

## 常见问题 FAQ

### Q1: 窗口太大或太小怎么办？
**A**: v5.0会自动适配您的屏幕尺寸，占屏幕90%。如果您想调整大小，可以：
- 拖动窗口边缘调整
- 点击"切换全屏"按钮
- 窗口大小会被记住

### Q2: 修改总币后，累计币怎么变了？
**A**: 这是正常的！因为：
```
总小码币 = 累计币 + 本周币

当您修改总币时：
- 本周币保持不变
- 累计币会自动调整
- 确保总币 = 累计币 + 本周币
```

### Q3: 可以撤销修改吗？
**A**: 目前不支持撤销功能。建议：
- 修改前确认数值
- 定期备份数据
- 如需恢复，使用备份文件

### Q4: 图表中学生太多，显示不完整？
**A**: v4.0已优化：
- 折线图区域支持滚动
- 使用鼠标滚轮上下滚动
- 每个学生的图表都会完整显示

### Q5: 高DPI显示器上文字太小？
**A**: 临时解决方案：
- Windows：右键应用图标 → 属性 → 兼容性 → 高DPI设置
- 选择"由系统增强"
- 未来版本将优化高DPI支持
