# v6.0 版本更新日志 - 高DPI自适应优化

## 版本信息
- **版本号**: v6.0
- **更新日期**: 2024-11-14
- **更新分支**: `fix-responsive-class-detail-bottom-visibility-150pct-1920x1080`

## 问题背景

### 用户反馈的问题
在150%系统缩放（Windows显示设置）+ 1920×1080物理分辨率的笔记本电脑上：
1. ❌ **班级详情页看不到下半部分** - 底部的"币数管理"控制区域被截断
2. ❌ **图表统计窗口的关闭按钮看不到** - 按钮在最底部，被挤出可见区域

### 技术原因
- **150%系统缩放**导致有效显示区域约为 **1280×720** 逻辑像素（而非1920×1080）
- 原v5.0代码使用固定高度（Treeview height=15行 × 40px = 600px），在720px有效高度下无法容纳所有内容
- 图表统计窗口关闭按钮放在最底部，内容过多时被截断

---

## 🎯 核心优化

### 1. 班级详情页自适应优化

#### ✅ Treeview高度动态计算
**文件**: `ui/class_detail_view.py` (第85-110行)

```python
# 动态计算Treeview高度，适应不同屏幕尺寸（特别是高DPI缩放场景）
screen_height = self.winfo_screenheight()

if screen_height <= 800:
    tree_height = 8   # 小屏幕或高DPI缩放场景
elif screen_height <= 1080:
    tree_height = 12  # 标准1080p显示
else:
    tree_height = 15  # 大屏幕
```

**优化效果**:
- 150%缩放场景（720p有效高度）：8行 × 35px = 280px（✅ 节省320px空间）
- 标准1080p：12行 × 35px = 420px
- 大屏幕（2K/4K）：15行 × 35px = 525px

#### ✅ 行高优化
- 原v5.0：`rowheight=40px`
- v6.0：`rowheight=35px`
- **节省空间**：每行节省5px，8行共节省40px

#### ✅ 标题内边距优化
- 原：`padding=(10, 8)`
- 新：`padding=(8, 6)`
- **效果**：标题行更紧凑，节省约10px

#### ✅ 整体滚动架构
**文件**: `ui/class_detail_view.py` (第721-748行)

```python
# 创建可滚动的主内容区域（整体滚动）
main_canvas = tk.Canvas(chart_window, bg='white', highlightthickness=0)
main_scrollbar = ttk.Scrollbar(chart_window, orient="vertical", command=main_canvas.yview)

scrollable_main_frame = ttk.Frame(main_canvas)

# 绑定鼠标滚轮到主Canvas
def _on_main_mousewheel(event):
    main_canvas.yview_scroll(int(-1*(event.delta/120)), "units")
main_canvas.bind_all("<MouseWheel>", _on_main_mousewheel)
```

**优化效果**:
- ✅ 移除了原来折线图区域的单独滚动（简化架构）
- ✅ 使用**整体滚动**，一个滚动条控制所有内容
- ✅ 鼠标滚轮滚动更流畅

## 🔧 技术细节

### 核心设计原则
1. **优先支持小屏幕** - 针对720p有效高度优化
2. **动态计算而非固定值** - 根据屏幕高度自适应
3. **简化滚动架构** - 单一滚动条控制所有内容
4. **关键控件固定位置** - 按钮等放在顶部固定区域
