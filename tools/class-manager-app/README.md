# 课堂管理系统 - 西瓜老师 / Classroom Manager

## 功能特性 / Features

### 1. 登录界面优化
- ✅ 渐变色动态标题（西瓜老师）
- ✅ 白色背景，界面元素正常显示
- ✅ 输入框仅支持英文字符
- ✅ 简洁的登录界面（无测试账号提示）
- ✅ 错误时不提示正确账号密码

### 2. 班级管理
- ✅ 单击班级按钮直接进入班级详情页
- ✅ 添加、修改、删除班级
- ✅ 右键班级按钮快速操作
- ✅ 全屏/窗口模式切换

### 3. 学生管理
- ✅ 添加、修改、删除学生
- ✅ 右键人名列快速操作（仅在人名列有效）
- ✅ 重复检查和确认对话框

### 4. 小码币管理（3周显示）
- ✅ 显示上上周、上周、本周、总计（共4列）
- ✅ 双击币数单元格可直接修改
- ✅ 自动计算总小码币（累计+本周）
- ✅ 修改币数后自动同步显示
- ✅ 周日期范围动态计算

### 5. 数据持久化
- ✅ 自动保存所有数据到本地CSV文件
- ✅ 数据存储位置：`tools/class-manager-app/storage_data/`
- ✅ 包含三个文件：
  - `classrooms.csv` - 班级信息
  - `students.csv` - 学生信息
  - `weekly_history.csv` - 周历史记录

## 使用说明 / Usage

### 启动应用
```bash
cd tools/class-manager-app
python3 main.py
```

### 登录

### 操作指南

#### 班级管理
- **进入班级**：单击班级按钮
- **修改班级名字**：右键班级按钮 → 修改班级名字
- **删除班级**：右键班级按钮 → 删除班级
- **添加班级**：点击"添加班级"按钮

#### 学生管理
- **添加学生**：点击"添加学生"按钮
- **修改学生姓名**：右键点击学生姓名 → 修改学生姓名
- **删除学生**：右键点击学生姓名 → 删除学生
- **修改小码币**：双击对应周的币数单元格

#### 周数据显示
- **上上周**：第2列，显示两周前的币数
- **上周**：第3列，显示上周的币数
- **本周**：第4列，显示当前周的币数
- **总小码币**：第5列，显示累计币数+本周币数

#### 数据持久化
- 所有操作自动保存到本地CSV文件
- 重启应用后数据自动加载
- 数据文件位置：`storage_data/`文件夹
- 可手动备份该文件夹保存数据

## 技术架构 / Architecture

### 目录结构
```
tools/class-manager-app/
├── main.py                 # 应用入口
├── data/
│   ├── models.py          # 数据模型
│   ├── store.py           # 数据存储和业务逻辑
│   └── excel_storage.py   # CSV持久化存储
├── ui/
│   ├── login_view.py      # 登录界面
│   ├── main_view.py       # 主界面（班级选择）
│   └── class_detail_view.py  # 班级详情界面
└── storage_data/          # 数据存储目录（自动创建）
    ├── classrooms.csv
    ├── students.csv
    └── weekly_history.csv
```

### 数据模型
- **Classroom**: 班级模型（名称、ID、学生列表）
- **Student**: 学生模型（姓名、ID、本周币数、累计币数、历史记录）

### 存储机制
- 使用CSV格式存储（Python标准库，无需额外依赖）
- 自动保存：所有增删改操作后自动保存
- 自动加载：启动时自动加载本地数据
- 首次运行：自动生成7个示例班级
