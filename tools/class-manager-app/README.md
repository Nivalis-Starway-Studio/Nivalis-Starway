# 课堂管理系统 - 功能优化版本

## 概述

这是一个基于Tkinter的课堂管理系统，用于管理班级、学生和小码币。经过全面优化，新增了多项功能并改进了用户体验。

## 🎯 主要优化功能

### 1. 登录界面优化 ✨
- **修复黑色背景问题**：设置白色背景，确保所有界面元素正常显示
- **渐变色标题**："西瓜老师"四个大字采用绿色渐变效果，视觉效果更佳
- **清晰的输入提示**：账号和密码输入框前有明确的中文标签
- **居中登录按钮**：改进布局，按钮居中显示

### 2. 班级管理增强 🏫
- **基本功能**：添加、修改、删除班级
- **右键菜单**：班级按钮右键可快速修改名字或删除班级
- **实时刷新**：班级列表动态更新，操作后立即显示最新状态
- **智能验证**：防止重复班级名称，所有操作都有确认对话框

### 3. 学生管理增强 👨‍🎓
- **基本功能**：添加、修改、删除学生
- **右键菜单**：学生表格行右键可快速修改姓名或删除学生
- **重复检查**：防止添加同名学生
- **操作确认**：删除操作需要用户确认，防止误操作

### 4. 5列显示优化 📊
- **4周数据**：上一周、本周、下一周、下下周
- **总计列**：显示累计小码币数量（累计币数 + 本周币数）
- **动态日期**：每列显示对应的日期范围（格式：月/日-月/日）
- **时间适应**：随着时间推移，自动保持正确的周格式

### 5. 全屏功能 🖥️
- **启动全屏**：程序启动时自动全屏显示，充分利用屏幕空间
- **切换按钮**：主界面和班级详情界面都有"切换全屏"按钮
- **跨平台支持**：Windows和Linux/Mac都支持全屏模式

## 📱 使用指南

### 班级管理
1. **添加班级**：点击"添加班级"按钮，输入班级名称
2. **修改班级**：右键点击班级按钮，选择"修改班级名字"
3. **删除班级**：右键点击班级按钮，选择"删除班级"
4. **进入班级**：左键点击班级按钮选中，然后点击"进入班级"

### 学生管理
1. **添加学生**：在班级详情页面，点击"添加学生"按钮
2. **修改学生姓名**：右键点击学生表格行，选择"修改学生姓名"
3. **删除学生**：右键点击学生表格行，选择"删除学生"
4. **查看学生信息**：左键点击学生表格行查看详情

### 币数管理
1. **更新周币**：选中学生后在"币数管理"区域输入新的周币数
2. **重置全班周币**：点击"重置全班周币"按钮，将周币加入累计币

### 显示控制
1. **全屏切换**：点击"切换全屏"按钮在全屏和窗口模式间切换
2. **返回主菜单**：在班级详情页面点击"返回主菜单"

## 🔧 技术特点

### 数据模型
- **Student模型**：包含姓名、周币、累计币、历史记录、唯一ID
- **Classroom模型**：包含班级信息和学生管理方法
- **数据持久化**：内存存储（生产环境可扩展为数据库）

### UI设计
- **响应式布局**：支持窗口大小调整
- **右键菜单**：提供快速操作入口
- **渐变色设计**：登录界面采用绿色渐变标题
- **白色背景**：解决黑色背景导致的显示问题

### 业务逻辑
- **周管理系统**：自动计算周数和日期范围
- **币数统计**：实时计算周币和累计币
- **数据验证**：防止重复和无效操作
- **错误处理**：完善的异常处理和用户提示
