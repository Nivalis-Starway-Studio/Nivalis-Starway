# 课堂管理系统

一个基于 Python Tkinter 的班级管理应用，专为教师设计，用于管理学生的小码币（奖励币）系统。

## 功能特点

### 1. 用户登录
- 安全的登录界面
- 演示账号：`xigua` / `123456`
- 输入验证和错误提示

### 2. 班级选择
- 直观的班级选择界面
- 显示 7 个预设班级（一年级A班 至 四年级A班）
- 每个班级显示学生数量
- 可快速切换不同班级

### 3. 班级详情管理
- **学生名单展示**：以表格形式显示所有学生信息
- **周币管理**：为学生分配每周的小码币奖励
- **累计币追踪**：自动累计学生的历史奖励
- **批量重置**：一键重置全班周币，并自动累加到累计币
- **实时统计**：显示班级总人数、本周总币数、累计总币数

### 4. 数据管理
- 内存数据存储（会话期间数据持久化）
- 支持多个班级和学生
- 币数数据实时更新

## 技术栈

- **Python 3.x**
- **Tkinter**：图形用户界面
- **ttk**：现代化的UI组件
- **dataclasses**：数据模型定义

## 安装和运行

### 环境要求
- Python 3.7 或更高版本
- Tkinter（通常随 Python 一起安装）

### 运行应用

在项目根目录下执行以下命令：

```bash
python3 tools/class-manager-app/main.py
```

或者进入应用目录后运行：

```bash
cd tools/class-manager-app
python3 main.py
```

## 使用说明

### 1. 登录系统
- 启动应用后，输入用户名 `xigua` 和密码 `123456`
- 点击"登录"按钮或按回车键登录

### 2. 选择班级
- 在主界面，点击任意班级按钮
- 确认选择后，点击"进入班级"按钮查看详情

### 3. 管理学生币数
- 在班级详情页面，点击表格中的学生行来选择学生
- 使用数字选择器调整新的周币数
- 点击"更新周币"按钮确认修改
- 币数更新后，统计信息会自动刷新

### 4. 重置周币
- 点击"重置全班周币"按钮
- 确认操作后，所有学生的周币将：
  - 累加到各自的累计币中
  - 周币重置为 0
- 适用于每周结算奖励币的场景

### 5. 退出登录
- 在主界面点击"退出登录"按钮
- 返回登录界面

## 预设数据

系统预设了 7 个班级，每个班级包含 3-4 名学生：

| 班级 | 学生数 | 班级ID |
|------|--------|--------|
| 一年级A班 | 4 | 1A |
| 一年级B班 | 4 | 1B |
| 二年级A班 | 3 | 2A |
| 二年级B班 | 3 | 2B |
| 三年级A班 | 4 | 3A |
| 三年级B班 | 3 | 3B |
| 四年级A班 | 4 | 4A |

每个学生都有初始的周币和累计币数据。

## 数据模型

### Student（学生）
- `name`：学生姓名
- `weekly_coins`：本周获得的小码币
- `cumulative_coins`：累计获得的小码币总数

### Classroom（班级）
- `name`：班级名称
- `class_id`：班级唯一标识
- `students`：学生列表

## 开发规范

### 代码组织
- 遵循 MVC 架构模式
- UI 层和数据层分离
- 使用 dataclass 定义数据模型

### 命名规范
- 类名：大驼峰命名法（如 `ClassDataStore`）
- 方法名：小写下划线命名法（如 `get_all_students`）
- 变量名：小写下划线命名法（如 `current_class_id`）

### 注释规范
- 所有模块、类、方法都有中文 docstring
- 复杂逻辑添加行内注释说明

## 常见问题

### Q: 应用关闭后数据会丢失吗？
A: 是的，当前版本使用内存存储，关闭应用后数据会丢失。如需持久化，可以考虑添加数据库或文件存储功能。

### Q: 可以修改班级数量吗？
A: 可以，在 `data/store.py` 文件的 `_load_sample_data()` 方法中修改班级数据。

### Q: 币数有上限吗？
A: 当前币数选择器范围是 0-100，可以在 `ui/class_detail_view.py` 中的 Spinbox 组件修改范围。

### Q: 支持哪些操作系统？
A: 支持所有可以运行 Python 和 Tkinter 的操作系统，包括 Windows、macOS 和 Linux。
