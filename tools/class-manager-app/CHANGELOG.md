# 更新日志 / Changelog

## 2024 - 全面优化版 / Comprehensive Optimization Release

### 🎨 用户界面优化 / UI Improvements

#### 登录界面 / Login View
- ✅ **动态渐变标题**：实现"西瓜老师"文字动态渐变效果（每300ms旋转颜色）
- ✅ **修复背景问题**：解决ttk.Frame不支持background参数导致的黑色背景错误

#### 班级管理界面 / Classroom Management View
- ✅ **单击进入**：点击班级按钮直接进入班级详情页，无需二次确认
- ✅ **右键快捷菜单**：右键班级按钮可快速修改名字或删除班级

- ✅ **响应式布局**：班级按钮网格自动调整，支持动态添加/删除

#### 班级详情界面 / Class Detail View
- ✅ **3周+总计显示**：调整为上上周、上周、本周、总计共4列（之前是5列）
- ✅ **双击修改**：双击上上周、上周、本周列的单元格可直接修改小码币数量
- ✅ **智能右键菜单**：右键菜单仅在人名列（第1列）有效，避免误操作
- ✅ **自动更新总计**：修改币数后自动刷新总计列（累计+本周）
- ✅ **日期范围显示**：每列标题显示对应周的日期范围（月/日-月/日）

### 🔧 核心功能 / Core Features

#### 数据持久化 / Data Persistence
- ✅ **CSV格式存储**：使用Python标准库csv模块，无需额外依赖
- ✅ **自动保存**：所有增删改操作后自动保存到本地文件
- ✅ **自动加载**：启动时自动从CSV文件加载数据
- ✅ **存储位置**：数据保存在`storage_data/`目录
- ✅ **三文件结构**：
  - `classrooms.csv` - 班级信息
  - `students.csv` - 学生基本信息
  - `weekly_history.csv` - 周历史记录

#### 小码币管理 / Coin Management
- ✅ **多周管理**：支持查看和修改上上周、上周、本周的小码币数量
- ✅ **历史同步**：修改历史周币数时，自动调整累计币数
- ✅ **总计计算**：总计=累计币数+本周币数，实时更新
- ✅ **输入验证**：修改币数时进行范围验证（0-1000）

#### 班级和学生管理 / Classroom & Student Management
- ✅ **完整CRUD**：支持班级和学生的添加、修改、删除操作
- ✅ **重复检查**：添加/修改时检查名称重复
- ✅ **确认对话框**：删除操作需要用户确认
- ✅ **实时刷新**：操作后立即刷新显示

### 🐛 Bug修复 / Bug Fixes

1. **修复tkinter错误**
   - 问题：`_tkinter.TclError: unknown option "-background"`
   - 原因：ttk.Frame不支持background参数
   - 解决：移除ttk.Frame的background参数，使用全局样式配置

2. **修复班级列表重复**
   - 问题：选择班级页面出现两份相同的7个班级
   - 原因：刷新逻辑重复渲染
   - 解决：统一使用`_populate_classroom_buttons()`方法，清空旧控件后重新渲染

3. **修复列索引错误**
   - 问题：双击修改币数时获取错误的值
   - 原因：列号(#2)和values索引(1)不匹配
   - 解决：添加index_map映射，正确获取values中的值

4. **修复历史周更新逻辑**
   - 问题：修改历史周币数不影响累计币数
   - 原因：历史周修改未同步到累计
   - 解决：在update_student_week_coins中增加diff计算逻辑

### 📝 使用建议 / Usage Tips

1. **数据备份**
   - 定期备份`storage_data/`文件夹
   - 可使用云同步保存数据

2. **修改币数**
   - 双击币数单元格最方便
   - 输入0-1000范围内的数字

3. **批量操作**
   - 使用右键菜单快速管理
   - 删除前会有确认提示

4. **全屏模式**
   - 启动时自动全屏
   - 点击"切换全屏"按钮可切换

5. **数据恢复**
   - 如需重置，删除`storage_data/`文件夹
   - 下次启动会自动生成示例数据
