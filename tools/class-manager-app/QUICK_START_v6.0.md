## ❓ 常见问题

**Q: 我的屏幕缩放不是150%，也能用吗？**  
A: 当然！v6.0支持所有缩放比例（100%-200%）和所有分辨率（720p-4K）。

**Q: 升级到v6.0会影响我的数据吗？**  
A: 不会！完全向后兼容，数据格式不变。

**Q: 如何查看学生列表更多行？**  
A: 使用学生列表右侧的滚动条，或使用鼠标滚轮。

**Q: 图表窗口太大/太小怎么办？**  
A: v6.0会自动调整为屏幕的85%，这是最佳尺寸。如需调整，可以拖动窗口边缘。

## 🐛 遇到问题？

如果遇到显示问题，请检查：
1. Windows显示设置 → 缩放与布局 → 确认是150%
2. 显示器分辨率 → 确认是1920×1080
3. 应用是否使用最新的v6.0版本

如问题仍未解决，请联系开发团队并提供：
- 系统缩放比例
- 显示器分辨率
- 问题截图
